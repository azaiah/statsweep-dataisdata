# Weekly sweep (for the Monday scheduled run)

Set this up once the Command Center is deployed. Ask Claude to "create a scheduled task every Monday at 5:00 am ET" and give it this prompt, plus the live URL and `INGEST_KEY`.

1. `GET https://team.statsweep.com/api/ingest/ids` with header `x-ingest-key: <INGEST_KEY>`. This returns the names, cities and states already in the portal. Never add any of them again.
2. Search YellowPages (and Google Maps if available) for "medical courier", "non emergency medical transportation", "medical transportation", "wheelchair transportation", "medical delivery" and "lab courier", rotating 40 metros a week so every state comes up once a month.
3. Keep only local operators that are both medical and transport. Drop fire, municipal and volunteer services, hospitals, air ambulance, national brokers and carriers, home-care franchises, toll-free-only listings and duplicates.
4. Open every listed website over HTTPS. A YellowPages placeholder, social page or no link counts as `web.status: "none"`; site builders and sites that don't load count as `"outdated"`; everything else is `"decent"`.
5. Build each lead with the same fields as `netlify/functions/seed-data.mjs` (id `ss-` plus a hash of name and phone, `stage: "new"`, `owner: null`, `log: []`, `sweep: "<YYYY-MM-DD>"`, `foundAt: <ISO>`). Scripts are generated by the app, so don't send them.
6. `POST https://team.statsweep.com/api/ingest` with header `x-ingest-key`, body `{ "docs": [ { "c": "leads", "id": "...", "data": { ... } }, ..., { "c": "sweeps", "id": "<YYYY-MM-DD>", "data": { "at": "<ISO>", "added": <n>, "by": "Claude", "summary": "...", "sources": [ ... ] } } ] }`, up to 500 docs per request.
7. If nothing new fits, still post the sweeps record and say so in the summary.
